# legacy_build (bukan bagian alur normal)

Skrip yang dulu mengonversi set ikon lama (512 px berwarna) menjadi set mask 96 px.
Butuh folder aset lama dari zip NekOS asli (tidak ikut kit ini), jadi **tidak bisa dijalankan dari kit saja**.
Path keluaran di dalam skrip masih memakai `source/`; kit ini sekarang memakai `default_skin/`.
Disimpan sebagai catatan asal-usul aset. Jangan dipakai untuk membuat skin baru: pakai `tools/to_mask.py`.
