# Main assets

This folder contains original/source artwork for NekOS. Assets are grouped by purpose:

- `branding/` — project logos, concept images, prototype icon, and artwork.
- `icons/app/` — 100 app-style icon assets (512×512) with `icons_index.json` and `icons_index.md`.
- `icons/ui/` — 120 UI icon assets (512×512) with `ui_index.json` and `ui_index.md`.
- `dynamic/tag_frame/` — animated tag/dialog frame source, spritesheet, preview, and metadata.

These are source/reference assets. The app's packaged runtime assets are maintained separately under `app/src/main/assets/`.
